# Repository guidance

- Read `PROJECT.md` before changing this project.
- Update `PROJECT.md` in every iteration that changes behaviour, architecture,
  schema, dependencies, integrations, deployment status or roadmap.
- Add an entry to `PROJECT.md` under **Histórico de iterações** in the same
  commit as the implementation.
- Keep the functional status and roadmap checkboxes honest; do not describe
  demonstration UI as production functionality.
- Record the validation commands used for the iteration.
